# 百炼英雄 · 简化版 —— 需求与开发说明

> 本文件是需求文档 + 开发备忘，后续修改 / 追加需求都记录在这里。

## 一、玩法需求（已确认）

1. **点击寻路移动**：点击地图任意位置，角色用 A* 寻路移动过去（四方向，不斜穿墙角）。
2. **墙体阻挡**：墙不可通行，寻路自动绕开；角色绝不穿墙。
3. **怪物阻挡**：角色移动路径上碰到怪物即停下，触发战斗。
4. **战斗 = 数值比大小**：角色数值 vs 怪物数值，大者胜，过程与结果都极简。
5. **遇怪即停**：碰到怪物后本次移动立即终止，角色停在怪物前一格。
6. **绿色路径线**：点击后从角色当前位置到目标绘制完整绿色虚线（包括怪物后面的部分）；角色移动时线从角色身后持续消失（绿线始终从角色当前位置延伸到目标）；**碰到怪物开战时，怪物后面的剩余绿线全部消失**；到达终点后目标圆圈隐藏。
   - **角色朝向**：初始按预制体当前 `scaleX` 正负决定；移动方向向左时角色 `scaleX` 变为负数（水平翻转），向右移动恢复为正数；**开战瞬间强制面向怪物**（怪物在左朝左、在右朝右），避免最后一步竖直走导致朝向残留；头顶数字标签反向缩放，不随角色镜像颠倒。角色真实朝向以 `Player.facing` 为准，切换 `role1` 时通过 `Player.getFacing()` 保留，不再用 `node.scale.x` 反推，避免经验缩放/白光期间误判成朝右。`Player.init()` 不再硬置朝右，战斗入口 `doBattle()` 会调用 `faceToWorldX()` 再播放攻击。
   - **角色动画**：初始播放 `idle`；点击移动播放 `run`；碰到怪物开战播放 `phyattack1`。战斗失败时角色也要先播放攻击动画，但目前只保留约 **0.5s** 的攻击表现，然后播放 `die` 一次并停在最后一帧，之后不再响应点击。失败死亡延迟参数在 `GameManager.ts` 的失败分支里调整。
   - **怪物动画**：初始播放 `idle`；开战时与角色同时播放 `phyattack`（怪物动画名，角色为 `phyattack1`）；判定**在攻击播放时就进行**——**怪物战力 > 角色** 时，不等待怪物攻击播完，当前约 **0.5s** 后角色播放 `die`；**角色战力 > 怪物** 时，角色攻击播放完成后怪物播放 `die`，怪物死亡流程结束后隐藏并吸收战力；相等按角色失败。
   - **战斗数字跳动**：判定在攻击播放时开始，双方头顶数字**同步加减，分 3 段、每段 0.3s**——赢家按输家战力分 3 段加上去，输家分 3 段减到 0（例：角色 10 vs 怪物 9，角色胜 → 角色 13/16/19，怪物 6/3/0）；结束时补齐精确值。

## 二、点击规则（已确认）

7. 点击可达空地：寻路移动。
8. 点击怪物：寻路目标就是怪物格，**绿线画到怪物脚下**（穿过怪物格）；角色走到怪物前一格停下即**原地开战**（和点击怪物身后一样）；怪物被墙完全围住无法到达时无反应。
9. 点击墙体：无反应（不移动、不画线）。
10. 点击不可达区域 / 地图外：无反应。
11. 移动中再次点击：打断当前移动，重新寻路。

## 三、战斗规则（已确认）

12. 触发：角色停在怪物前一格即战斗。
13. 规则：**角色战力 > 怪物战力**为胜；**相等或小于则角色失败**。
14. 胜：怪物隐藏消失，角色战力 **+ 怪物战力**，数字/HUD 同步刷新；败：角色死亡（隐藏），弹出“失败”。
    - **怪物死亡掉落经验球（规则）**：经验球挂在 `GameWorld/Drops` 专门层级（代码自动创建），不挂怪物身上、不在场景预摆；目前为代码画的占位球，`ExpOrb.exp` 已预留经验字段。
      1. 角色战力 > 怪物：**角色攻击动画播放完后**才生成 2 个经验球（在怪物位置，和怪物死亡动画同时开始）。
      2. **散落方向**按怪物在角色的方位（左上 / 左下 / 右上 / 右下）决定：怪物在右/上则方向取正。
      3. 第一跳：2 个球 **0.5s** 抛物线散落，**X 方向**一个移动 **60**、一个移动 **90**（两个球 **Y 完全一致**：垂直位移相同、弧线最高点相同）；第一跳结束立刻第二跳：**0.3s** 再向右移动 **30**（抛物线）。
      4. 第二跳结束立刻**飞向角色，0.2s 到达**（无等待）。
      5. 掉落过程中怪物头顶数字保持 **0** 不动；**死亡动画完整播放完 + 2 个球都到达角色**后，怪物用 `active=false` 隐藏（不销毁），球同时消失，战斗结束。
    - **收到经验球反馈**：2 个球到达角色的瞬间，角色显示白光约 **0.08s**，同时 0.1s 缩放变 1.2，再 0.1s 恢复原大小（`Player.playExpPulse`）。白光使用 `role/ExpWhiteGlow` 节点，不移动 `spine` 或骨骼动画。
    - **收尾兜底**：怪物死亡动画 3s 内未播完、或经验球 3s 内未归位时，强制结束流程（隐藏怪物 + 补一次白光），避免怪物头上的 0 一直不消失。

## 宝箱（box）

- **摆放**：宝箱节点放在 `GameWorld/BoxLayer` 下（用户手动创建该层级），挂 `Chest` 组件，子节点挂 **Label**（文本 = 开箱获得的战力值）；启动时 GameManager 扫描场景里所有 Chest 组件注册。
- **拾取**：角色走进宝箱拾取范围（节点大小 × `footprintScale`，默认 0.8）即停下，**不限角色战力**。
- **流程**：角色播放攻击动画 → 攻击播完 → 宝箱打开并消失（`active=false`）→ 角色战力 **+ 宝箱 Label 数值**，头顶数字 / HUD 刷新 → 角色切换成 **role1**（`GameManager.role1Prefab`，位置/战力保留，动画名与 role 一致，之后移动/打怪都用 role1）。
- **实现**：`Chest.ts`（读 Label、算拾取占格）；`Grid` 增加宝箱占格表 + `firstOccupantOnSegment`（路径上第一个怪物/宝箱）；`Player` 碰到宝箱播攻击、播完回调 `onChest`；`GameManager.openChest` 处理加分/消失/切换。
    - **角色可继续移动**：角色攻击动画播放完（判定胜）后战斗即结束，可以继续点击移动/打怪；怪物从寻路表移除、死亡动画和经验球在后台继续，经验球飞向角色时实时追踪角色位置。初始化（spawnMonsters）时会把所有怪物 `active=true` 并播 idle。
    - **战斗必须"走进怪物占格"才触发**：`Grid.firstOccupantOnSegment` 不把角色当前站着的怪物算作触发（避免打完上一只后站在别的怪物重叠占格里、一点击就秒开战）；只有移动**真正进入**怪物占格才开战（格子遍历只作候选，命中后再用真实线段与格子矩形精确相交校验，斜穿格角不算）。
    - **缩放脉冲不干扰朝向**：收到经验球的缩放用 `pulseScale` 乘数实现，和角色朝向（facing）分开计算，脉冲不会导致角色后续朝向卡住。
15. 表现：不做 VS 展示；失败提示保留；动画已接入（角色、怪物都有动画）。
    - **死亡界面**：角色死亡（失败）时弹出"再来一次"按钮（复用原返回按钮的重载场景逻辑：`director.loadScene('game')`）；原"返回"按钮已移除；"退出"等其他按钮逻辑后续再加。

    - **胜利界面**：打败最后一只怪物时弹出“游戏胜利”按钮，位置和“再来一次”一致；点击后暂时复用重载场景逻辑（`director.loadScene('game')`）。最后一只怪物优先按 `Monsters/monster1` 判断；如果场景里找不到 `monster1`，则以当前扫描到的最高战力怪物作为兜底。

## 四、配置（已确认）

16. 目前只设计 **1 关**：地图尺寸、角色出生点 / 初始战力写在 `scripts/GameConfig.ts` 的 `Level1` 里（当前为占位，数值后续由用户提供）。
    - **地图换算**：背景图 `bg` 尺寸 2336×1792，节点缩放为 1，所以 **1 世界单位 = 1 图片像素**；`tileSize` 就是每格像素数。`cols = 2336 / tileSize`、`rows = 1792 / tileSize`。
    - 当前取 `tileSize=20`（格子加密，墙轮廓更精细）→ `117×90` 格（2340×1800），盖满整张图。
    - **角色显示大小固定 50，与格子大小解耦**（`GameManager` 用 `fitToTile(node, 50)`，初始 role 和切换 role1 都保持一致），改 tileSize 不影响角色视觉大小。
    - **点击范围 = 格子范围**（`cols×tileSize` × `rows×tileSize`，中心与图片中心重合），图片范围内点击都会响应，范围外无反应。
17. **怪物在场景里摆放**：把 `prefabs/monster/monster1~4.prefab` 拖到 `scene/game.scene` 的 `Monsters` 节点下，位置用编辑器直接拖；战力直接改怪物预制体 / 场景实例下的 **Label 文本**（文本即战力数值），颜色、字号、大小（缩放）全部由编辑器控制，**代码不做怪物缩放**。
    - **怪物占格 = 实际视觉大小**：启动时按怪物节点 `UITransform × 缩放 × footprintScale` 计算它覆盖的格子，路径进入这些格子即触发战斗；改怪物体积/缩放会自动重新计算。`footprintScale` 默认 0.6（战斗范围更贴近身体），想更早/更晚触发战斗就在怪物组件上调大/调小。
18. 角色：`prefabs/role/role.prefab` 下挂 **Label**（文本即初始战力，颜色等直接在编辑器改）；角色镜像翻转时，代码只对 Label 做反向缩放，保证文字不镜像、大小不变。
19. 地面由代码用 Graphics 生成；**墙只用 WallRegion 定义**（不再从 `GameConfig.walls` 读取、不再画紫色占位方块）。
20. **不规则墙体 = WallRegion 组件**：在 `Walls` 节点下挂一个空节点，添加 `WallRegion` 组件，二选一：
    - **矩形模式**（`regionType = Rect`）：直接用节点 `UITransform` 的宽高框定墙区域；
    - **多边形模式**（`regionType = Polygon`，默认）：在 Inspector 里填 `polygon` 顶点数组（相对该节点的本地坐标，逆时针），任意形状都行。
    启动时 `GameManager` 自动扫描场景里的所有 `WallRegion`，把格子中心落在区域内的格子全部烘焙（不再需要一个个在 `GameConfig.walls` 里列格子）。**节点支持旋转/缩放**——烘焙时会把格子中心换算到墙体本地坐标再判断，结果和编辑器里看到的形状一致。`debugDraw` 开启时运行时画半透明形状（墙=红、平台=蓝、台阶=黄），方便对位置。
    - **mode 用途**：`Wall` 墙（挡路）；`Platform` 平台（`height` 层可走区域，如 `height=1`）；`Stair` 台阶（可通行，连接 0 层与 `height` 层）。
    - **高度规则**：同高度可走；高度差 1 且其中一格是台阶才可走（不能直接爬上/跳下平台边缘）；高度差 > 1 不可走。角色 A* 会自动绕到台阶处上下。
    - **同层寻路（如地面到地面、平台到平台）**：只要起点和终点都不在台阶上，台阶视为墙，路径绕行不穿行；**目标是台阶 / 起点在台阶上 / 跨层（地面↔平台）**时，台阶可走（上、下都行）。
    - **路径拉直也校验高度**：绿线平滑时逐格按高度规则检测，不会把平台当平地拉直线穿过去。

## 五、怪物点击黄光 / Shader（已确认）

21. **点击怪物黄光**：点击怪物时，怪物显示黄色描边 / 发光约 **0.5s**，同时角色仍然要按正常寻路逻辑移动，不能因为显示黄光而打断点击移动。
22. **GlowHolder 层级**：在 `GameWorld` 同级创建 `GlowHolder`，专门作为临时黄光显示层；不要把 `GlowHolder` 放到 `Monsters` 下面，否则怪物扫描、结算或隐藏逻辑可能把它当成怪物相关节点处理而报错。
23. **黄光实现方式**：`GlowHolder` 上挂 `UITransform`、`Sprite`、`GlowRim`、`Snapshot`，材质使用 `GlowRim.mtl`。怪物本体是 Spine，当前材质不能直接挂到 Spine 上，所以点击时把怪物临时放到 `GlowHolder` 里做快照发光，结束后再还原到原父节点、原位置、原缩放、原层级顺序。怪物结构允许是“怪物节点本身挂 Spine、子节点挂 Label”；当前先不处理数字的黄光排除，后续再专门调整。
24. **显示/隐藏规则**：黄光显示结束后只隐藏/还原，不销毁怪物节点；死亡或重新开始时也要优先隐藏残留黄光，避免重影或结算阶段访问到错误节点。
25. **Snapshot 注意点**：`Snapshot.layer` 必须固定使用，不要每次递增；否则再次进入游戏可能出现两个角色/怪物重影。默认情况下 Snapshot 会递归把目标节点切到快照层，隐藏/销毁时再恢复；如果是角色白光这类“真实角色仍要被主相机看到”的效果，要开启 `preserveTargetLayer`，让目标节点同时保留原显示层和快照层。销毁时只解绑 `camera.targetTexture`，不要主动销毁共享纹理。
26. **GlowRim 注意点**：Snapshot 模式下不要强制把节点 scale 改成 1，`centerScale` 保持 1；怪物的真实大小必须由原节点缩放决定，黄光不能让怪物或角色瞬间变大/变小。
27. **角色收经验白光**：`role` 下新增 `ExpWhiteGlow`，与 `spine` 同级，建议层级放在 `spine` 后、`Label` 前。节点挂 `UITransform`、`Sprite`、`Snapshot`、`GlowRim`，默认隐藏；`Snapshot.target` 指向 `role/spine`，收经验时显示约 **0.08s** 后隐藏。不要把 `spine` 下的骨骼动画移动到 `ExpWhiteGlow`。白光显示前由 `Player.syncExpWhiteGlowBounds()` 自动按 `spine` 包围框调整位置/尺寸；`ExpWhiteGlow` 本地 `scaleX` 使用 `Player.facing` 做反向补偿（朝左为 -1，朝右为 1），避免快照内容已随 `role` 翻转后又被父节点二次翻转成反方向。当前先回到原快照显示方式，仅缩短显示时间观察异常角色闪现是否降低。

## 七、代码结构

| 文件 | 职责 |
|---|---|
| `scripts/GameConfig.ts` | 单关配置：地图尺寸、角色出生点 / 战力（墙体由 WallRegion 定义） |
| `scripts/Grid.ts` | 格子数据、占用表、A* 寻路、坐标换算 |
| `scripts/Monster.ts` | 怪物组件：从场景位置占格、从子 Label 读战力 |
| `scripts/Player.ts` | 角色组件：沿路径移动、逐格检测、战斗回调、头顶 Label 同步与反向缩放 |
| `scripts/PathLine.ts` | 绿色虚线绘制 + 逐段消失 + 目标圆圈 |
| `scripts/GameManager.ts` | 入口：搭建场景、生成墙/地面、实例化角色、读取场景怪物、点击输入、战斗与 UI |
| `scripts/WallRegion.ts` | 墙体区域：矩形或多边形区域，启动时把覆盖到的格子烘焙成墙（含调试着色） |
| `scripts/CameraFollow.ts` | 相机跟随：开局先对准角色（身体中心）；死区按画布尺寸 x `deadZoneRatio`（当前 0 = 一直跟随），超出后 150px/s 匀速追尾，追上即停 |

路径表现：已加入**路径拉直 + 拐点贴墙**——`Grid.buildMovePath` 去掉冗余拐点，并把转弯点外移到墙角外侧 `WALL_GAP`（当前 6px，越小越贴墙）处，路径贴着墙体外侧走、不穿墙；**拉直只绕墙、不绕怪物**——绿线可以直线穿过怪物体内画到目标（不会在怪物附近产生锯齿弯折）；`PathLine` 用二次贝塞尔把拐角画成曲线虚线；角色沿世界坐标点移动（`Player.moveTo(Vec3[])`），移动时检测线段进入的第一个怪物格，在怪物体内边缘停下开战。

## 八、场景结构（`scene/game.scene`）

```
Game
└── Canvas
    ├── Camera（自动挂 CameraFollow：角色在屏幕一半范围内相机不动，超出后以 150px/s 匀速追赶，追上即停）
    ├── GameWorld（挂 GameManager；Grid 自动添加）
    │   ├── Ground
    │   ├── Walls（可挂多个 WallRegion 节点定义任意形状墙体，不再画紫色占位墙）
    │   ├── Monsters（monster1~4 预制体实例，位置/战力在编辑器里调）
    │   ├── Player（运行时由 playerPrefab 实例化）
    │   └── PathLine
    └── UILayer
        ├── BackButton（返回 / 重载场景）
        ├── PowerHUD（角色战力）
        └── BattleResult（战斗结果提示）
```

## 九、接入步骤

1. 打开 `scene/game.scene`。
2. 选中 **GameWorld** 节点，添加组件 **GameManager**。
3. 把 `prefabs/role/role.prefab` 拖到 `GameManager.playerPrefab`。
4. 怪物：确认 `Monsters` 节点下已摆放 monster1~4（预制体实例），每个怪物下面的 Label 填好战力数字（如 `134`）。
5. 角色：`prefabs/role/role.prefab` 下的 Label 填好初始战力（如 `4407`），颜色、位置在编辑器里调。
6. 点预览运行：点击地面移动、点击怪物战斗、点击墙 / 被围怪物无反应。

**用 WallRegion 画不规则墙**（例如截图里的 L 形 / 回字形墙体）：
1. 在 `Walls` 节点下新建空节点（如 `WallRegion_1`），添加组件 `WallRegion`。
2. 默认多边形模式：在 Inspector 的 `polygon` 里填顶点（相对该节点的本地坐标，如截图墙体外轮廓的几个角点）。
3. 开启 `debugDraw` 运行预览，红色半透明形状即墙体；同时点击该区域，角色不会走进去，寻路会自动绕行。
4. 对齐后想去掉红框，把 `debugDraw` 关掉即可（烘焙不受影响）。
5. 简单矩形墙可以直接把 `regionType` 改成 `Rect`，用 UITransform 大小框住即可，不用填顶点。

> 演示：场景里已内置一个 `WallRegion_Demo` 节点（左上角 L 形红色区域，覆盖格子 2,4 / 2,5 / 0,6 / 1,6 / 2,6），可直接运行看效果，不需要时删除该节点。

- 寻路、点击怪物、点击空地移动统一改为 Touch-End 松手时触发；Touch-Start 不再触发角色移动或战斗入口。
